# 小鹿AI · 完整产品 HTML5

按用户 Figma 页面与确认后的产品逻辑整合的移动端 React + TypeScript + Vite + GSAP 项目。首页不再是独立语音测试页，而是三入口的完整产品宿主。

## 预览

需要 Node.js 24+、npm。进入本目录：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:4173/ 。首页从装备预订、营地推荐或周边行程开始。装备预订先确认城市，随后填写人数、预算、6天天气/日历日期、场地类型。

方案详情可直接结算，或点击“添加装备”进入完整语音开场。在助手下方输入“加焚火炉和折叠小桌椅”，即可返回原套餐与增配结果。输入框最右绿色图标为独立Live助手入口，左侧为普通消息的按住说话切换。

## 构建与部署

```sh
npm test
npm run build
npm run preview
```

`dist/` 是已构建的静态部署目录，可放到 HTTPS 静态服务器，支持子目录。无需服务器渲染。请用 HTTP/HTTPS 打开，不要双击 file:// 下的 index.html。麦克风依赖 HTTPS 或本机 localhost 的安全上下文。

## 当前数据状态

这是可运行和可静态部署的完整前端交互版。天气、地点、装备库存和推荐内容有明确示例标识；支付只在本地创建演示订单，不会扣款或向商家发送预订。

已接入 Web Audio 实际麦克风采集和本地中文语音转写，不再依赖浏览器联网的 Web Speech 识别服务。打开语音助手时预热模型，按麦克风后才采集音频；音频不上传、也不写入历史存储，转写文字沿用现有对话流程。首次使用需要加载约139 MB模型文件及WASM运行文件，浏览器缓存后复用；手机上的识别速度和内存占用仍需真机验收。实现、验证及部署说明见 `LOCAL_SPEECH.md`。

没有接入大模型Realtime、商业ASR、实时天气、地图、真实库存或微信/支付宝商户支付。正式上线交易需要服务端对接及校验。

`src/product/types.ts` 为核心数据结构和统一计价；`Results.tsx` 的 `makePlans` 为可替换演示推荐目录。正式接入应由服务端返回完整报价与商品、库存，并以支付回调核准订单。请勿将密钥放入前端。
